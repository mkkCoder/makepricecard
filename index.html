Questions

Short answers

Do I need an account?

No. There is nowhere to sign up — there is no server to sign up to.

Where is my menu stored?

In this browser, on this device. Clearing site data clears it. Export JSON or CSV if you want a backup.

What does Pro change?

Watermark off, four extra templates, and logo upload. Core editing and export stay free.

Is client-side licensing “secure”?

Determined users can bypass browser checks. That is an intentional tradeoff for running without a backend.
